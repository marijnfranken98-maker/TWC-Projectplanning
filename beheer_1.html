Plakken uit Excel / Autotask

Kopieer de regels (zonder kopregel) en plak ze hieronder. Kolommen in deze volgorde:
Klant · Project · Engineer(s) · Type · Startmaand · Eindmaand
Type: alles met "sales" wordt Sales, de rest Klant. Maand: een nummer (10), een naam (okt) of 2026-10. Bestaat de combinatie klant + project al, dan wordt die bijgewerkt; anders toegevoegd.
⚙ GitHub-koppeling
Eenmalig instellen. Alles wordt alleen in déze browser bewaard.
  1. Ga op GitHub naar Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Kies bij Repository access alleen de planning-repo, en zet bij Permissions → Contents op Read and write.
  3. Plak het token hierboven. Klaar — Opslaan naar GitHub zet de planning direct live (GitHub Pages heeft ±1 minuut nodig, het bord ververst zichzelf).
